Prepared September 21, 2026. Local-test candidate only: Windows x64 and ARM64 with one shared source archive. No GitHub publication, update enablement or user-library reset was performed.

## Implemented scope

- In-app preparation dialog for retained PDFs and rendered-page documents. No extra preparation tab or redundant whole-document confirmation.
- Explicit PDF-reader handoff leaves the dialog and prepared job available. Opening the reader does not rebuild the PDF.
- Done, Close and Escape stop preparation and clean job-owned temporary resources. Active transfers and locked copies defer cleanup with honest pending/unconfirmed status.
- Clear/Cancel and Prepare again remain available. Downloads, original library PDFs, stored page images, metadata and backups are preserved.
- Native selections of every size use PDF handoff from the dialog. Browser-neutral instructions name Chrome, Edge and Firefox as Windows support targets.
- Job-owned external-reader copies use unique ownership and retry cleanup. Conservative orphan cleanup ignores unknown files.
- Existing local-test isolation, rendered import fallback, persistent upload logging, render-worker responsiveness changes and v1.2.8 updater code are preserved.
