# AdvisePoint Docs v1.3.0 candidate 10 verification

September 22, 2026. Local testing only, with matching x64/ARM64 packages and
shared source. No GitHub publication, update enablement or library reset.

## Implemented behavior

- **Large selections:** 51 or more selected pages use the unchanged original
  when available, without image-to-PDF preparation. The FULL original opens
  for subsets, with explicit original-range instructions.
- **Smaller selections:** 1–50 pages retain their existing preparation path.
  The threshold is selected count, not ending page number.
- **Rendered imports:** New imports retain original bytes alongside page
  images. An additive `pdf_rendered` flag preserves rendered viewer identity.
- **Older image-only entries:** Exact-file attachment verifies SHA-256,
  publishes the file without overwriting another original, and changes only
  retention metadata. Existing pages, chunks and descriptive metadata remain.
  Missing fingerprints, mismatches and unexpected existing files are refused.
- **Download control:** The initial extracted-text section toolbar has a
  fourth icon, Download original PDF. Server-side file availability gates it.
  Hover and keyboard focus expose its label; a download response preserves
  original bytes and filename, including Unicode filenames.
- **Cleanup:** The dialog stays open after handoff. Done cleans app-owned
  temporary files, never library originals or downloaded user copies.
  Explicit saved-page preparation remains available with candidate-9
  child-process isolation, exit validation, diagnostics and idle protection.

The original is retained in the library's originals folder beside its SQLite
database, not duplicated as a SQLite blob. Backup and reversible deletion
include it. PDF security settings are not rewritten. Windows reader associations,
loading time and physical printing remain field-test responsibilities.
