# AdvisePoint Docs v1.3.0 final build

Final production-mode packaging uses the candidate 13 application source without PDF/runtime feature changes. The added changes are standalone maintenance utilities, production packaging guards and release documentation.

## Rebuild

Use Node 20 or newer and the committed lockfile. Do not set `VITE_APD_LOCAL_TEST`; unset it if inherited.

```sh
npm ci
npm run build:nobump
```

In PowerShell, remove the candidate flag with `Remove-Item Env:VITE_APD_LOCAL_TEST -ErrorAction SilentlyContinue` before building. `dist/build-mode.json` must contain `"local_test":false`.

Use the verified v1.2.8 production baselines and their architecture-specific native runtime modules:

```sh
node scripts/package-windows.mjs --baseline /path/to/AdvisePoint-Docs-v1.2.8-x64.zip --output /path/to/AdvisePoint-Docs-v1.3.0-x64.zip --arch x64 --x64-modules "/path/to/x64/AdvisePoint Docs/node_modules"
node scripts/package-windows.mjs --baseline /path/to/AdvisePoint-Docs-v1.2.8-arm64.zip --output /path/to/AdvisePoint-Docs-v1.3.0-arm64.zip --arch arm64 --arm64-node "/path/to/arm64/AdvisePoint Docs/node/node.exe" --arm64-modules "/path/to/arm64/AdvisePoint Docs/node_modules"
node scripts/package-source.mjs --output /path/to/AdvisePoint-Docs-v1.3.0-source.zip
```

Run packaging sequentially because the Welcome Guide is regenerated. No `--local-test` option is used. The packager refuses a local-test client build in production mode.

## Required gates

- **Package identity:** Version 1.3.0; correct ARCH and Node 20.18.1; no CANDIDATE, LOCAL_TEST_ONLY, local-test wrapper or local-test readme in final Windows packages.
- **Application identity:** Both architectures contain identical shared distribution files and production-mode launchers/update controls.
- **Runtime preservation:** Updater, Node executable and native modules match the verified v1.2.8 architecture baselines.
- **Utilities:** Both packages contain matching reset and cleanup helpers, launchers and START-FRESH.txt. Neither is called during startup.
- **Reproduction:** Independently extract the shared source, rebuild, and compare every distribution file with both packaged applications.
- **Documentation:** Regenerate and inspect the Welcome Guide; keep source and external release notes/checksums current.
- **Safety:** Run disposable reset/cleanup tests including port/link/identity refusal, copy corruption, source mutation, staged rollback and deletion failure.

No GitHub publication or live installation is performed by these build commands. Test only disposable libraries in the build environment.

## Fixture-independent PDF check

When the supplied manuals and previously rendered 724-page fixture are unavailable,
set `APD_SYNTHETIC_ONLY=1` explicitly for `pdf-integration.test.mjs` and
`pdf-handoff.test.mjs`. This skips only the real-manual integration case, actual
724-page attachment case and its restored-page assertion. Synthetic range,
permission, attachment, backup/restore and viewer checks still run.

The large-print suite already skips real-manual checks when `APD_MANUALS` is absent.
Do not include the fixture-dependent print-dialog or full rendered-print suites
without `APD_RENDER_FIXTURE`. Report these omissions, not a full candidate rerun.
