# AdvisePoint Docs v1.3.0 candidate 11 verification

Date: September 22, 2026. Scope: print-range input correction, local testing only.

## Correction

From and To now use string drafts. Clicking or focusing a field selects its
whole number; Backspace can leave it empty while a replacement is entered.
Values normalize on blur or Print, not on every keystroke. Invalid/empty values
return to the current viewer page, large values clamp to the last page, and
reversed endpoints retain the existing ordered-range behavior.

Real keyboard testing also exposed the viewer's global zero/arrow shortcuts
intercepting input. Editable controls now keep their own keys. Initial print
values are set only when opening the menu, so continuous page tracking does
not reset a range during editing.

## Automated results

- Print-dialog suite: 8 passed, including actual click, Backspace and keyboard
  typing in both Chromium and Firefox, for retained and rendered PDFs.
  Covers multi-digit values including zero, Tab select-all, empty drafts,
  upper bounds, invalid values, reversed ranges and exact preparation URLs.
  Existing handoff, download, cancellation, cleanup, transfer and original

- Original-PDF handoff and local-candidate suites: 17 passed. Covers the

- Viewer navigation suite: 8 passed, including rapid scrolling, distant jumps,

These 33 focused checks were run for candidate 11. The complete candidate-10
347-test campaign was not repeated and is not claimed as candidate-11 testing.

## Packaging release gates

The accompanying package-verification evidence checks archive integrity,
candidate/version markers, correct native PE architecture, matching application
bundles, matching shared source, isolated launchers, and v1.2.8 runtime/updater
byte preservation. An independent extraction of the source ZIP is rebuilt in
local-test mode and compared with the packaged application distribution.

No browser or server dependencies were changed. No reset utility was run, no
GitHub release was published, and updates remain disabled.
